# CHURNGUARD AI

Customer Churn Prediction & Retention Intelligence System.

## Workflow
Raw Data → Data Understanding → Cleaning → EDA → Feature Preparation → Model Training → Evaluation → Improvement → Prediction → Business Insight

## Run
Upload `CHURNGUARD_AI_Colab.ipynb` to Google Colab and run cells from top to bottom.

## Dataset
The notebook automatically loads IBM's public Telco Customer Churn dataset.

If MainCrafts gives you an official CSV, replace only the dataset-loading cell.

## Models
- Logistic Regression
- Random Forest
- Improved Random Forest using GridSearchCV + class balancing
